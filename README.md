# Version Control Implementation

## 📌 Project Overview
This project demonstrates GitHub version control using multiple modules.

## 🌿 Branches Used
- login-module
- dashboard-module
- cpc-recommendation
- report-generation

## 🔄 Workflow Followed
1. Created repository in GitHub
2. Created separate branches for each module
3. Added files in respective branches
4. Created pull requests
5. Performed code review
6. Merged branches into main
7. Handled merge process
